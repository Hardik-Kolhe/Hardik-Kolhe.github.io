Heart Stroke Prediction Using AI

Python, TensorFlow, Scikit-learn GitHub Repository

Project Overview

This research developed an AI system to predict heart strokes using ECG analysis and medical data. Our CNN model achieved 95% accuracy in detecting myocardial infarction (heart attack) from ECG signals, significantly outperforming traditional diagnostic methods.

Key Achievements

  • 95% accuracy in MI detection using 2D CNN on ECG leads V5 & V6
  • Identified optimal ECG leads for stroke prediction
  • Developed HIPAA-compliant clinical interface with Streamlit
  • Integrated machine learning (GBC: 95.3% accuracy) and deep learning approaches

Key Visualizations

System Architecture

Implementation: Our architecture processes ECG data through AWS services and provides predictions via a HIPAA-compliant Streamlit interface for medical professionals.

ECG Lead Processing

Key Finding: Leads V5 and V6 showed optimal performance (95% accuracy) compared to other lead combinations (80% accuracy).

Methodology

Data Sources

  • Tabular data: 5,110 patient records from Kaggle (age, hypertension, glucose, etc.)
  • ECG images: 12-lead ECGs from Mendeley Data (MI patients, abnormal heartbeats, normal cases)

Data Source: Mendeley Data (CC BY 4.0 License).

Technical Approach

Data Processing

Cropped ECG leads, handled imbalanced data, feature selection

Machine Learning

Gradient Boosting Classifier (95.3% accuracy)

Deep Learning

2D CNN on ECG leads (95% accuracy)

Deployment

Streamlit web app with doctor/patient portals

Impact

This system enables:

  • Earlier detection of heart disease when intervention is most effective
  • Reduced healthcare costs through automated analysis
  • Improved accessibility of advanced cardiac diagnostics
