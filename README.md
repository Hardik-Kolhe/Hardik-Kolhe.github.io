# Hardik Kolhe — Portfolio

Personal portfolio website (React + Vite). All application code lives in [`web/`](web/).

## Quick start

```bash
cd web
npm install
npm run dev
```

## Deploy

GitHub Pages deploys automatically from `web/dist` on push to `main` (see `.github/workflows/deploy.yml`).

Manual build:

```bash
cd web
npm run build:gh-pages
```
